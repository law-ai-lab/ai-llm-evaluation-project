# Factuality Error Taxonomy

This project documents common factuality errors found in AI-generated responses.

The goal is to build a reusable evaluation framework for identifying, explaining, and correcting factual problems in large language model outputs.

## Error Categories

1. Fabricated Facts
2. Unsupported Claims
3. Outdated Information
4. Numerical Errors
5. Citation Errors
6. Misleading Wording
7. Missing Context
8. Overgeneralization
9. Contradictions

## Evaluation Method

Each case follows this structure:

1. Identify the factual claim.
2. Determine the necessary context.
3. Find appropriate evidence.
4. Compare the claim with the evidence.
5. Assign an evaluation.
6. Explain the decisive reason.
7. Suggest a corrected response.

## Core Principle

A professional factuality evaluation follows this sequence:

**Claim → Context → Evidence → Comparison → Rating → Explanation**
